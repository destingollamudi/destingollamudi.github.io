Get your Music User Token

  1. Generate a developer token: 
    APPLE_MUSIC_TEAM_ID=... APPLE_MUSIC_KEY_ID=... \
APPLE_MUSIC_PRIVATE_KEY_PATH=./AuthKey_XXXX.p8 \
node scripts/apple-music-dev-token.mjs
  2. Paste it below and click Connect.
  3. Sign in with the Apple ID that has your Apple Music subscription.
  4. Copy the token it shows you into the APPLE_MUSIC_USER_TOKEN GitHub secret.
